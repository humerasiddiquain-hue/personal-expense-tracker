# SpendWise — Personal Expense Tracker 💰

A beginner-friendly personal finance dashboard built with **HTML, CSS and JavaScript**. Track income and expenses, view your balance, and understand spending by category.

## Features

- Add income and expense transactions
- Choose a category and date
- Automatically calculate total income, expenses and balance
- View a category-wise spending overview
- Search transactions and filter by type
- Delete transactions
- Save data in browser LocalStorage
- Responsive modern dashboard layout

## Technologies

- HTML5 — page structure
- CSS3 — styling and responsive layout
- JavaScript — app logic and calculations
- LocalStorage — saving transactions in the browser

## How to run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in a browser.
4. Select **Add transaction** to record income or an expense.

No installation or server is required.

## GitHub Pages deployment

1. Create a repository named `personal-expense-tracker`.
2. Upload all four project files to the repository's main branch.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish your site.

## Important note

This is a learning project. Transaction data is stored only in the current browser using LocalStorage. It is not a bank-connected service, and clearing browser data can remove saved transactions.
